# Hand-entered listings

Put one JSON file per venue here, for venues the collector can't fetch or only
partly fetches. The collector merges them into `listings.json` on every run, and drops
any showing whose start time has passed, so you can leave a file in place and
add the next month's dates to it.

Copy `20261024_example.json` to a new name (any `*.json` without "example" in
the name, e.g. `20261101_slaughtered-lamb.json`) and edit it.

| Field | Required | Notes |
|---|---|---|
| `venue` | yes | Display name. If `venue_slug` matches a scraper, the scraper's name is used instead. |
| `venue_slug` | no | e.g. `slaughtered-lamb`. Use the scraper's slug (`python -m listings list-venues`) to add to a scraped venue. |
| `category` | no | Default for every showing in the file: `film` (default) or `music`. |
| `showings[].title` | yes | |
| `showings[].start` | yes | `2026-11-20T20:00` (London time) or with an offset. |
| `showings[].doors` | no | `19:30` (same day) or a full datetime. |
| everything else | no | `lineup`, `genre`, `price`, `runtime_minutes`, `booking_url`, `image_url`, `tags`, `category` per showing. |

If a manual showing has the same venue, title and start as a scraped one, the
scraped one is kept, so it's safe to add only the shows a scraper missed.

Check your files without fetching anything:

    python -m listings check-manual

A broken file is reported and skipped; it never stops the other venues
publishing.

Suggested venues to fill in (their automatic sources are thin):
The Slaughtered Lamb, Folklore, and The Troubadour (only its first 50 events
are visible to the scraper).
